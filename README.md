# Rootkit Analysis Research

A research paper completed as part of my cybersecurity coursework at California State University, Dominguez Hills.

## Overview

This paper explores Linux and Windows rootkits, their evolution, attack methods, common detection techniques, and defensive security practices.

## Topics Covered

- Rootkit fundamentals
- User-mode vs. Kernel-mode rootkits
- Historical rootkit incidents
- Linux detection tools
  - chkrootkit
  - rkhunter
  - Lynis
- Windows security protections
- Secure Boot
- Kernel Lockdown
- Virtual machine security
- VMware ESXi rootkit activity
